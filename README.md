DESCRIPCIÓN DEL PROYECTO

EcoRecarga es una aplicación web en Python que digitaliza y fomenta el reciclaje comunitario. Permite a los ciudadanos ubicar puntos de acopio en un mapa, registrar sus entregas de materiales reciclables y acumular puntos según el peso para canjearlos por recompensas, mientras ofrece a los administradores el control de ubicaciones, inventarios y reportes gráficos de impacto ambiental.
